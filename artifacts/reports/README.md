# 评测报告

本目录保存评测脚本生成的原始报告。报告按生成时的内容保留，包括未通过的运行，不重新生成或手工修改。方法和结果的解读见 [评测与验证](../../docs/evaluation.md)。

| 目录 | 内容 |
| --- | --- |
| `retrieval/` | 检索基准（v2、v3 语料）和 v3 的检索层矩阵 |
| `llm/` | 真实模型的端到端评测报告、生成层矩阵、失败归因 |
| `reliability/` | 多进程故障注入测试，SQLite 与 PostgreSQL，包含修复前后的各次运行 |
| `application/` | 应用配置下的真实调用冒烟（几个问题的路径验证，不是准确率评测） |

运行数据库、日志和调用账本保存在本地 `.cache/`，不纳入版本库。
