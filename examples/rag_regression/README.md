# 回归集

这里保存端到端评测中确认失败过的查询，以及一份不得退化的阈值文件，用于检测回归，不能证明系统质量。

## 文件

- `cases.jsonl`：23 条查询，是 v3 语料测试集中至少在一个条件下失败的全部查询（改述提问 17 条、多片段 5 条、直接提问 1 条）。每行包含问题、相关片段、失败的条件和错误类别，以及应用的 BM25 检索器当前返回的前 3 个片段。由 `scripts/build_regression_set.py` 根据 `artifacts/reports/llm/failure-attribution-v3-20261011.json` 生成。
- `thresholds.json`：误答上限、引用校验违规上限、各条件正确作答数的下限，每项都写明了取值依据。

## 检查内容

`tests/test_regression_gate.py` 不联网运行，检查三件事：

- 入库的评测报告满足阈值。人为把误答数、正确作答数、违规数改坏后，门槛能分别发现。
- 入库的错误分析报告，与用当前规则重新分析得到的结果一致。
- 应用的 BM25 检索器对 84 条测试查询返回的前 3 个片段，与评测报告中的记录逐条一致；对这 23 条回归查询，也与 `cases.jsonl` 一致。

单独运行门槛：`python -m eval.regression_gate`。使用新报告时加 `--report`。

## 局限

- 向量检索依赖本地嵌入模型，CI 中不重新检索，向量条件的数字只能对照入库报告核对。
- 阈值取自当前观测值。0/28 误答对应的 95% 置信区间上限约为 12%，门槛只能发现退化，不能说明系统安全。
- 错误分析由一位复核人完成，没有第二人独立标注。
