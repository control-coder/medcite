# 回归集

这里放端到端评测里**确认失败**的查询，以及一份不得退化的阈值。它是回归检测用的，不是质量证明。

## 文件

- `cases.jsonl`：23 条查询，是 v3 语料 test 组里至少在一个条件下失败的全部查询（17 条换说法、5 条多片段、1 条直接问）。每行有问题、正确片段、失败的条件和归因类别，以及应用 BM25 检索器此刻返回的前 3 个片段。由 `scripts/build_regression_set.py` 根据 `artifacts/reports/llm/failure-attribution-v3-20261011.json` 生成。
- `thresholds.json`：误答上限、逐字绑定违规上限、各条件有用回答下限，每条写明取值依据。

## 校验什么

`tests/test_regression_gate.py` 零网络运行：

- 入库评测报告满足阈值；人为把误答、有用回答数、违规数改坏，门槛能分别发现。
- 入库的归因报告等于用当前规则重新归因的结果。
- 应用的 BM25 检索器对 84 条 test 查询返回的前 3 个片段，与评测报告里记录的逐条一致，对这 23 条回归查询也与 `cases.jsonl` 一致。

`python -m eval.regression_gate` 可单独跑门槛，换一份新报告时加 `--report`。

## 限制

- 向量检索依赖本地嵌入模型，CI 里不重新检索，向量条件的数字只能由入库报告核对。
- 阈值取自当前观测值。0/28 误答的 95% 区间上限约 12%，门槛只能发现退化，不能说明系统安全。
- 归因由一位复核人完成，没有第二人独立标注。
