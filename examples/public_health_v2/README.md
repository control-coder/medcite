# 公开中文科普检索评测集 v2

版本 public-health-excerpts-v2，采集日期 2026-10-08。在 v1（8 个 chunk、16 条查询）的基础上扩展，v1 的 chunk 与查询原样保留（v1 目录不改），用于回答“语料变大后检索与弃答是否仍然成立”。

| 项目 | 数量 |
| --- | --- |
| WHO 中文页面 | 51 篇（事实清单与问答页） |
| 摘录 chunk | 178 条，每条 1–2 个连续句子 |
| 查询 | 168 条：可回答 112，不可回答 56 |

## 文件

- `chunks.jsonl`：沿用 `KnowledgeChunk` 字段。`text` 是页面正文的逐字短引，标题与来源只放在元数据里，不参与索引。
- `queries.jsonl`：`sample_id`、`split`（dev/test）、`bucket`、`question`、`gold_evidence_ids`、`rationale`、`origin`。
- `sources.json`：每篇页面的标题、URL、页面显示日期、采集日期、使用限制，以及它贡献的 chunk 与小节。

## 查询分桶

可回答：

- `direct`：沿用摘录里的关键词提问。
- `paraphrase`：口语或同义改写，刻意避开摘录的关键名词（例如“屋里太闷怎样透透气”对应通风定义）。
- `multi`：需要两条及以上摘录，金标准列出全部。

不可回答（`gold_evidence_ids` 为空，正确行为是弃答）：

- `near_miss`：与语料共享主题词，但摘录里没有答案（具体价格、阈值、年份、本地数据等）。
- `uncovered`：常见健康问题，但语料没有涉及该疾病（痛风、湿疹、失眠等）。逐词检索确认语料中不出现。
- `out_of_scope`：与健康无关（车险、天气、编程等）。

## 划分

- v1 的 dev 查询仍为 dev，v1 的 check 查询作为 test。
- 新增查询按桶分层，桶内按 `sha256(sample_id)` 排序后交替分配 dev/test，可复现。
- 混合权重 α 与弃答阈值只在 dev 上选择，test 只报告（见 `eval/retrieval_benchmark.py`）。

## 构建与核对方式

- 页面通过 `scripts/public_corpus.py fetch` 抓取为纯文本并放在仓库外的缓存目录，不入库。
- 每条摘录用 `scripts/public_corpus.py verify` 逐字核对页面正文（忽略空白差异）。2026-10-08 对本目录全部 178 条摘录核对通过，其中包含 v1 的 8 条。
- 四个主题组（传染病、慢性病、生活方式与营养、环境心理伤害与母婴）分别采集后合并。合并时去重：B、C 两组各自采集了同一篇口腔健康内容，删除 2 条重复 chunk 并把相关金标准改指向保留的 chunk；四组各自生成的同类范围外问题（车险、天气、编程、旅游）去重后保留每类第一条，共删除 12 条。
- 不收录治疗方案、药品名与剂量。

## 局限（请随结果一起引用）

- **查询由 AI 辅助撰写，不是真实用户日志，也不是盲测。** direct 桶的措辞贴近摘录，指标偏乐观；paraphrase、near_miss、uncovered 桶更接近困难场景。
- 金标准经过一次汇集式复核：对 BM25 双字与稠密检索各自的前两名中高分的非金标准结果做人工检查，发现并修正了 oral 重复 chunk 导致的金标准遗漏。复核看过 dev 与 test 的查询，只修正了金标准，没有据此调整任何参数；但仍不能排除其他遗漏，也没有第二位标注者，没有一致性（Kappa）数据。
- 没有医学专家审核。这些数据只检验“能否找到并展示出处明确的原文”，不检验医学正确性。
- 页面日期取页面显示日期，多数是最近更新日期，不是首次发布日期。内容会随 WHO 更新而变化，逐字核对只对采集日有效。
- 使用依据：WHO 网站使用条款要求注明 WHO 为来源并给出 URL，大段复制或非教育、非商业用途需要事先书面授权（2026-10-08 读取）。本数据集只保留必要的短引和出处，仅用于非商业工程评测，未取得全文再分发许可。公开发布或商用前应自行确认条款。
