# 公开科普正文短摘录回归集

版本 public-health-excerpts-v1，采集与固定查询日期 2026-09-20。流感、新冠防护、高温防护三个主题，8 篇 WHO 中文原始网页，各保留一个连续短摘录，不是全文知识库或模拟主题标签。全部按普通科普标记 level_5_other，不能借发布机构名声提高证据等级。

sources.json 记录标题、来源、段落、日期、语言、使用限制与核实方式。实际 HTTP 200 正文已逐字核对摘录，页面日期为当次展示日期，不推断为首次发布日期。网页完整内容只放忽略的临时目录，不入库。原候选卫健委页面 HTTP 412 且浏览器无法取得正文，未采纳；原候选查询未跑实验，替换语料后重新固定了本查询集。

chunks.jsonl 沿用 KnowledgeChunk；短引各为一片，不人为切碎，标题及来源元数据不参与文本索引。未导入治疗、剂量、图片或附件。公开可读不等于全文可再分发，仅保留必要短引与出处；扩充前另核实使用权。

queries.jsonl 在首次对照运行前固定。dev/check 各 8 条，各 6 条有相关集合、2 条无证据问题。check 不用于调权、调阈值或改参考集合；口语同义表达与有词面重合却缺少答案的失败必须保留。部分相关片段不等于能回答问题全部细节。小样本为工程参考，不是盲测、专家标注或医学金标准。

只比较空格切分与连续中文双字切分 BM25，不翻译、不下载向量/NLI 模型。字面匹配不代表否定/同义词理解或语义支持。历史短摘录仅演示来源追踪，不用于患者诊疗。
