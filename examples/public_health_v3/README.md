# 公开中文科普检索评测集 v3

版本 public-health-excerpts-v3，采集日期 2026-10-10。在 v2 的基础上只增加干扰用的摘录，用来回答“语料再变大，检索的命中率会掉多少，检索智能体是否更有用”。v2 的 178 条 chunk（原样、同样顺序）、168 条查询和金标准一字未改，v2 目录不动。

| 项目 | 数量 |
| --- | --- |
| WHO 中文页面 | 131 篇（v2 的 51 篇 + 新增 80 篇） |
| 摘录 chunk | 498 条（v2 的 178 条 + 新增 320 条），每条 1–2 个连续句子 |
| 查询 | 168 条，与 v2 完全相同：可回答 112，不可回答 56 |

## 文件

与 v2 相同：`chunks.jsonl`、`queries.jsonl`、`sources.json`。新增 chunk 的 `chunk_id` 形如 `kb_<页面标识>_<序号>`，来源字段与 v2 一致。

## 新增摘录如何选取

由 `scripts/extend_corpus.py` 生成，规则固定、不看评测问题，同样的输入得到同样的输出：

1. 从 WHO 中文事实清单索引抓取 195 篇页面，排除 v2 已有的页面后，按页面标识的哈希排序，取前 80 篇能抽出至少 3 条摘录的页面。
2. 每页在小节标题下的段落里，取连续 1–2 句、30–110 字的窗口；含参考文献编号、链接、冒号、“以下/如下”等依赖上下文的句子以及以“此外/然而/这/它”开头的句子不取。
3. 每页等间隔取 4 条。
4. 屏蔽词：页面标题或摘录里含下列任一词的页面和句子不收，用来避免语料无意中变得能回答“不可回答”查询（痛风、湿疹等）：
   痛风 湿疹 失眠 痔疮 腰椎 肾结石 结石 甲状腺 荨麻疹 痛经 帕金森 带状疱疹 脂肪肝 幽门螺杆菌 结膜炎 红眼 手足口 水痘 偏头痛 更年期 前列腺 胃炎 多动症 注意力 痤疮 脚气 类风湿 贫血 血红蛋白 乳头状瘤 人乳头瘤 癣 足癣。
   因此癣（ringworm）和人乳头状瘤病毒两篇页面被整篇排除。

复现命令（页面先用 `scripts/public_corpus.py fetch` 抓到仓库外的缓存目录，`--exclude-terms` 填上面的词）：

```
python scripts/extend_corpus.py --html-dir <页面目录> --pages-out <纯文本目录> --max-pages 80 --exclude-terms <屏蔽词>
```

核对：对新增的 320 条摘录用 `scripts/public_corpus.py verify` 逐字核对页面正文（忽略空白差异），2026-10-10 全部通过。

## 防止新摘录无意中回答了查询

做过一次人工检查：用 BM25 双字和稠密检索对 168 条查询排序，列出所有出现在“不可回答”查询前 5 名、或把金标准挤出“可回答”查询前 3 名的新增摘录，逐条阅读。结论是没有一条新摘录直接回答了不可回答的查询；少数相关主题的摘录（单纯疱疹对应带状疱疹和水痘，骨关节炎对应类风湿，腰痛康复对应腰椎间盘）是真实的相近干扰，予以保留，它们正是用来测拒答是否稳定的。

## 局限（请随结果一起引用）

- 沿用 v2 的全部局限：查询由 AI 辅助撰写，不是真实用户日志；没有第二位标注者；没有医学专家审核。
- 新增摘录是机械抽取的，不保证句子本身有信息量，也没有逐条核对它们与评测查询是否在语义上完全无关；上面的人工检查只覆盖检索排在前面的那一部分。
- 新增页面的主题偏传染病和公共卫生，对日常健康类查询的干扰比对传染病类查询弱。
- 页面日期、使用依据同 v2：内容会随 WHO 更新而变化，逐字核对只对采集日有效；只保留必要短引和出处，仅用于非商业工程评测，未取得全文再分发许可。
